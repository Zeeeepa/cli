# TestUI YAML Action Schema v1.0

## Overview

The TestUI YAML schema defines a declarative format for browser automation tasks. Actions are executed sequentially in a sandboxed Chrome environment with network and filesystem restrictions enforced by `@anthropic-ai/sandbox-runtime`.

## Schema Structure

```yaml
version: "1.0"
metadata:
  name: "Test Name"
  description: "Test description"
  author: "Generated by Z.ai"
  created: "2024-01-15T10:30:00Z"
  
sandbox:
  network:
    allowedDomains:
      - "localhost"
      - "127.0.0.1"
      - "app.example.com"
    deniedDomains:
      - "*"
  filesystem:
    allowRead:
      - "."
      - "/tmp"
    allowWrite:
      - "./screenshots"
      - "./logs"
    denyRead:
      - "~/.ssh"
      - "~/.aws"
  
actions:
  - type: "navigate"
    url: "https://app.example.com"
    
  - type: "click"
    selector: "#login-button"
    
  - type: "type"
    selector: "input[name='email']"
    text: "user@example.com"
```

## Action Types

### 1. navigate

Navigate to a URL.

```yaml
- type: navigate
  url: "https://example.com/page"
  waitUntil: "networkidle" # Optional: load, domcontentloaded, networkidle
  timeout: 30000 # Optional: timeout in ms, default 30000
```

**Fields**:
- `url` (required): Target URL
- `waitUntil` (optional): Navigation wait condition
  - `load` - Wait for load event
  - `domcontentloaded` - Wait for DOMContentLoaded event
  - `networkidle` - Wait for network to be idle
- `timeout` (optional): Navigation timeout in milliseconds

**Example**:
```yaml
- type: navigate
  url: "https://app.example.com/login"
  waitUntil: "networkidle"
  timeout: 60000
```

---

### 2. click

Click on an element.

```yaml
- type: click
  selector: "#submit-button"
  button: "left" # Optional: left, right, middle
  clickCount: 1 # Optional: 1 for single, 2 for double click
  delay: 100 # Optional: delay between mousedown and mouseup
  timeout: 5000 # Optional: timeout for selector
```

**Fields**:
- `selector` (required): CSS selector for target element
- `button` (optional): Mouse button - `left`, `right`, `middle`
- `clickCount` (optional): Number of clicks (1 or 2)
- `delay` (optional): Delay in ms between mousedown and mouseup
- `timeout` (optional): Timeout for element selection

**Example**:
```yaml
- type: click
  selector: "button.login-submit"
  button: "left"
  clickCount: 1
```

---

### 3. type

Type text into an input field.

```yaml
- type: type
  selector: "input[name='username']"
  text: "testuser"
  delay: 50 # Optional: delay between keystrokes in ms
  clear: true # Optional: clear existing text first
  timeout: 5000 # Optional: timeout for selector
```

**Fields**:
- `selector` (required): CSS selector for input element
- `text` (required): Text to type
- `delay` (optional): Delay between keystrokes in ms
- `clear` (optional): Clear existing text before typing
- `timeout` (optional): Timeout for element selection

**Example**:
```yaml
- type: type
  selector: "#email-input"
  text: "user@example.com"
  clear: true
  delay: 50
```

---

### 4. wait

Wait for a condition or duration.

```yaml
# Wait for selector
- type: wait
  condition: "selector"
  selector: ".loading-complete"
  state: "visible" # Optional: visible, hidden, attached, detached
  timeout: 10000

# Wait for duration
- type: wait
  condition: "timeout"
  duration: 2000

# Wait for navigation
- type: wait
  condition: "navigation"
  timeout: 30000
```

**Fields**:
- `condition` (required): Wait condition type
  - `selector` - Wait for element to match state
  - `timeout` - Wait for fixed duration
  - `navigation` - Wait for navigation to complete
- `selector` (required for `selector`): CSS selector
- `state` (optional for `selector`): Element state
  - `visible` - Element is visible
  - `hidden` - Element is hidden
  - `attached` - Element is in DOM
  - `detached` - Element is removed from DOM
- `duration` (required for `timeout`): Wait duration in ms
- `timeout` (optional): Maximum wait time

**Examples**:
```yaml
# Wait for element to be visible
- type: wait
  condition: "selector"
  selector: "#dashboard"
  state: "visible"
  timeout: 10000

# Wait 2 seconds
- type: wait
  condition: "timeout"
  duration: 2000

# Wait for page navigation
- type: wait
  condition: "navigation"
  timeout: 30000
```

---

### 5. screenshot

Capture a screenshot.

```yaml
- type: screenshot
  path: "./screenshots/dashboard.png"
  fullPage: false # Optional: capture full page
  selector: "#main-content" # Optional: screenshot specific element
  quality: 90 # Optional: JPEG quality 0-100
  type: "png" # Optional: png or jpeg
```

**Fields**:
- `path` (required): Output file path
- `fullPage` (optional): Capture entire scrollable page
- `selector` (optional): Capture specific element only
- `quality` (optional): JPEG quality (0-100), ignored for PNG
- `type` (optional): Image format - `png` or `jpeg`

**Examples**:
```yaml
# Full page screenshot
- type: screenshot
  path: "./screenshots/full-page.png"
  fullPage: true
  type: "png"

# Element screenshot
- type: screenshot
  path: "./screenshots/header.png"
  selector: "header.main-header"

# JPEG with quality
- type: screenshot
  path: "./screenshots/preview.jpg"
  type: "jpeg"
  quality: 85
```

---

### 6. evaluate

Execute JavaScript in the page context.

```yaml
- type: evaluate
  script: |
    return {
      title: document.title,
      url: window.location.href,
      userAgent: navigator.userAgent
    }
  returnVariable: "pageInfo" # Optional: store result
```

**Fields**:
- `script` (required): JavaScript code to execute
- `returnVariable` (optional): Variable name to store result

**Examples**:
```yaml
# Get page information
- type: evaluate
  script: |
    return {
      title: document.title,
      url: location.href
    }
  returnVariable: "pageData"

# Click element via JS
- type: evaluate
  script: |
    document.querySelector('#submit').click()

# Scroll to bottom
- type: evaluate
  script: |
    window.scrollTo(0, document.body.scrollHeight)
```

---

### 7. assertExists

Assert that an element exists.

```yaml
- type: assertExists
  selector: ".success-message"
  state: "visible" # Optional: visible, hidden, attached
  timeout: 5000 # Optional: timeout for assertion
  message: "Success message not found" # Optional: custom error message
```

**Fields**:
- `selector` (required): CSS selector
- `state` (optional): Expected element state
  - `visible` - Element must be visible
  - `hidden` - Element must be hidden
  - `attached` - Element must be in DOM
- `timeout` (optional): Assertion timeout
- `message` (optional): Custom error message on failure

**Examples**:
```yaml
# Assert element exists and is visible
- type: assertExists
  selector: "#dashboard"
  state: "visible"
  message: "Dashboard did not load"

# Assert element exists in DOM
- type: assertExists
  selector: ".hidden-field"
  state: "attached"
```

## Variables and Templating

Reference stored variables using `${variableName}` syntax:

```yaml
- type: evaluate
  script: "return document.querySelector('#username').textContent"
  returnVariable: "currentUser"

- type: type
  selector: "#welcome-message"
  text: "Hello ${currentUser}!"
```

**Built-in Variables**:
- `${timestamp}` - Current Unix timestamp
- `${date}` - Current date (YYYY-MM-DD)
- `${random}` - Random string (8 chars)

## Sandbox Configuration

### Network Restrictions

```yaml
sandbox:
  network:
    allowedDomains:
      - "localhost"
      - "127.0.0.1"
      - "*.example.com" # Wildcard subdomain
      - "api.service.com"
    deniedDomains:
      - "*" # Block all other domains
```

**Domain Patterns**:
- Exact match: `"example.com"`
- Wildcard subdomain: `"*.example.com"` (matches `api.example.com`, not `example.com`)
- IPv4: `"127.0.0.1"`, `"192.168.1.1"`
- Localhost: `"localhost"`
- Block all: `"*"`

### Filesystem Restrictions

```yaml
sandbox:
  filesystem:
    allowRead:
      - "." # Current directory
      - "/tmp"
      - "./config"
    allowWrite:
      - "./screenshots"
      - "./logs"
      - "./output"
    denyRead:
      - "~/.ssh"
      - "~/.aws"
      - "~/.env"
    denyWrite:
      - "/etc"
      - "/usr"
      - "/System"
```

**Path Patterns**:
- Absolute: `"/etc/hosts"`
- Home-relative: `"~/.ssh/id_rsa"`
- Current directory: `"."`, `"./logs"`
- Glob patterns: `"./config/**"`, `"/var/log/*"`

## Complete Example

```yaml
version: "1.0"

metadata:
  name: "Login and Dashboard Test"
  description: "Test user login flow and verify dashboard loads"
  author: "Generated by Z.ai"
  created: "2024-01-15T10:30:00Z"

sandbox:
  network:
    allowedDomains:
      - "localhost"
      - "127.0.0.1"
      - "app.example.com"
      - "api.example.com"
    deniedDomains:
      - "*"
  
  filesystem:
    allowRead:
      - "."
      - "/tmp"
    allowWrite:
      - "./screenshots"
      - "./logs"
    denyRead:
      - "~/.ssh"
      - "~/.aws"

actions:
  # Navigate to login page
  - type: navigate
    url: "https://app.example.com/login"
    waitUntil: "networkidle"
    timeout: 30000
  
  # Take screenshot of login page
  - type: screenshot
    path: "./screenshots/01-login-page.png"
    fullPage: false
  
  # Fill in email
  - type: type
    selector: "input[name='email']"
    text: "testuser@example.com"
    clear: true
  
  # Fill in password
  - type: type
    selector: "input[name='password']"
    text: "SecureP@ssw0rd"
    clear: true
  
  # Click login button
  - type: click
    selector: "button[type='submit']"
    button: "left"
  
  # Wait for dashboard to load
  - type: wait
    condition: "selector"
    selector: "#dashboard"
    state: "visible"
    timeout: 10000
  
  # Take screenshot of dashboard
  - type: screenshot
    path: "./screenshots/02-dashboard.png"
    fullPage: true
  
  # Assert user menu is visible
  - type: assertExists
    selector: ".user-menu"
    state: "visible"
    message: "User menu not found after login"
  
  # Get page title
  - type: evaluate
    script: "return document.title"
    returnVariable: "pageTitle"
  
  # Wait for data to load
  - type: wait
    condition: "timeout"
    duration: 2000
  
  # Take final screenshot
  - type: screenshot
    path: "./screenshots/03-final-state.png"
```

## Error Handling

### Action Failures

Each action can fail for various reasons:

1. **Timeout**: Element not found within timeout period
2. **Selector Invalid**: CSS selector is malformed
3. **Element Not Interactable**: Element exists but can't be interacted with
4. **Navigation Error**: Page fails to load
5. **Assertion Failure**: assertExists condition not met
6. **Sandbox Violation**: Network/filesystem access denied

### Error Response Format

```yaml
error:
  action: 3 # 0-indexed action number
  type: "timeout"
  message: "Timeout waiting for selector '#submit-button'"
  selector: "#submit-button"
  timestamp: 1705315800000
```

## Validation Rules

1. **Version**: Must be "1.0"
2. **Actions**: Must be non-empty array
3. **Selectors**: Must be valid CSS selectors
4. **URLs**: Must be valid HTTP/HTTPS URLs
5. **Paths**: Must be relative or absolute filesystem paths
6. **Timeouts**: Must be positive integers
7. **Sandbox Domains**: Must be valid domain patterns

## Best Practices

1. **Use specific selectors**: Prefer IDs over classes
2. **Add timeouts**: Prevent indefinite waits
3. **Take screenshots**: Aid debugging
4. **Use wait actions**: Ensure page state before interaction
5. **Minimal network access**: Only allow required domains
6. **Protect credentials**: Never hardcode secrets
7. **Test locally**: Verify YAML before automation
